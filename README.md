### ⚡ Systems Builder & IT Student
Building lightweight web experiments, air-gapped local AI, and browser privacy tools. Zero cloud dependencies when it matters. Currently working toward a B.S. in Information Technology.

---

### 🚀 Deployments & Active Projects

* **[Project Marceline](https://helloterminalio.com/marceline)**
  *Air-gapped, local-inference AI assistant.*
  Built with **Meta Llama 3.2**, **Unsloth**, and **ChromaDB** vector retrieval behind a **FastAPI** core. Designed for complete offline operation and privacy.

* **[VanishPoint](https://helloterminalio.com/vanishpoint)** & **[DHBlocker](https://helloterminalio.com)**
  *Custom browser privacy extensions.*
  Engineered to kill persistent tracking scripts, isolate background telemetry, and reduce general browser bloat. 

* **[Terminalio](https://helloterminalio.com)**
  *Interactive dev portfolio and blog.*
  A retro web console and typing engine built using vanilla web technologies and deployed via **Cloudflare Pages**.
